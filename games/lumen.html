🤖 Lumen

Bringe alle blauen Felder zum Leuchten. Tippe auf einen Befehl, um ihn anzuhängen, oder ziehe ihn auf einen Programmplatz. Tippe auf einen belegten Platz, um ihn zu entfernen. Vorwärts geht nur auf gleicher Höhe; Sprung geht eine Stufe hinauf oder beliebig weit hinunter. P1 und P2 rufen Unterprogramme auf. Start führt das Programm aus, Schritt führt einen Befehl aus. Reset setzt nur den Roboter zurück.
